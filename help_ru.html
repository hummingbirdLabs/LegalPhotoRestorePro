🚀Быстрый старт

  1. Скачайте PhotoRestore Pro из Microsoft Store.
  2. Запустите приложение — без аккаунта, без регистрации, без интернета.
  3. Выберите функцию на главном экране.
  4. Импортируйте фото через Импорт на панели инструментов. Форматы: PNG, JPEG, WebP, BMP, TIFF.
  5. Обработайте изображение — Начать обработку (ИИ) или Создать превью (без ИИ).
  6. Сохраните через Сохранить вверху справа.
Совет: После обработки можно вернуться на главную и открыть другую функцию — ваши изображения остаются на месте.

📷Восстановление фото

Три подхода к восстановлению — от сверхбыстрых правок до полных конвейеров ИИ.

🗃️

Восстановление старых фото ИИ

Идеально для очень старых, выцветших или испорченных семейных фото, требующих полного восстановления ИИ.

  1. Нажмите Восстановление старых фото (с значком ИИ).
  2. Импортируйте фото.
  3. (Опционально) Включите Подавление шума ИИ при сильной зернистости.
  4. Нажмите Начать обработку. Пять этапов: сглаживание, подавление шума, улучшение цвета, увеличение 4×, резкость.
  5. Просмотрите сравнение и Сохраните.
Время: 15–60 секунд в зависимости от размера и оборудования. DirectML ускоряет с GPU.
⚡

Быстрое восстановление

Идеально для слегка состаренных фото — результат за миллисекунды.

  1. Нажмите Быстрое восстановление.
  2. Импортируйте фото.
  3. Нажмите Старт — мгновенный результат.
  4. Сравните и Сохраните.
Время: Менее 1 секунды. Только традиционные алгоритмы.
🏛️

Классическое восстановление

Идеально для сканов высокого разрешения из музеев, архивов или профессиональных сканеров (600+ DPI).

  1. Нажмите Классическое восстановление.
  2. Импортируйте скан высокого разрешения.
  3. (Опционально) Включите Удаление царапин.
  4. Нажмите Старт.
  5. Сохраните в исходном разрешении.
Время: Менее 2 секунд. Идеально для архивных процессов.

🤖Улучшение ИИ

Две функции ИИ, которые выводят ваши фото за рамки традиционного редактирования.

🔍

Увеличение 4× ИИ

Идеально для изображений низкого разрешения, которым нужно больше деталей.

  1. Нажмите Увеличение 4× (с значком ИИ).
  2. Импортируйте изображение.
  3. Нажмите Начать обработку. ИИ увеличивает до 4× исходных размеров.
  4. Сравните и Сохраните.
Примечание: Показывает точные размеры — напр. 2048 × 1536 → 8192 × 6144.
🎨

Раскрашивание ИИ ИИ

Идеально для чёрно-белых фото — история оживает в естественных цветах.

  1. Нажмите Раскрашивание ИИ (с значком ИИ).
  2. Импортируйте ч/б фото.
  3. (Опционально) Выберите Тип объекта — Портрет, Пейзаж, Архитектура, Общее.
  4. (Опционально) Настройте Интенсивность цвета и Теплоту.
  5. Нажмите Начать раскрашивание.
  6. Просмотрите и Сохраните.
Время: 4–8 секунд для раскрашивания ИИ.

🛠️Умные инструменты

Шесть лёгких и сверхбыстрых утилит для повседневных задач с фото.

✨

Улучшение цвета

Идеально для тусклых фото — 8 визуальных пресетов рядом.

  1. Нажмите Улучшение цвета и Импортируйте фото.
  2. Создать превью — 8 пресетов рендерятся одновременно.
  3. Переключайтесь клавишами ← / →.
  4. Экспорт выбранного.
🔧

Удаление царапин

Идеально для отсканированных фото с видимыми царапинами, разрывами или сгибами.

  1. Нажмите Удаление царапин и Импортируйте скан.
  2. Начать удаление. Морфологический анализ и умное заполнение.
  3. Просмотрите и Сохраните. Время: 1–3 секунды.
Важно: Для общего старения используйте Восстановление ИИ или Классическое восстановление.
🎞️

Сетка 9 фильтров

Идеально для быстрого изучения художественных стилей — 9 фильтров параллельно.

  1. Нажмите Сетка 9 фильтров и Импортируйте фото.
  2. Создать превью.
  3. Переключайтесь клавишами стрелок.
  4. Экспорт выбранного.
✂️

Обрезка и конвертация

Идеально для обрезки, изменения размера или конвертации между форматами.

  1. Нажмите Обрезка и конвертация и Импортируйте фото.
  2. Режим: Свободное выделение, Конкретный размер или Масштаб.
  3. Формат вывода: PNG, JPEG, WebP, BMP или TIFF.
  4. Применить превью, затем Экспорт.
Примечание: Масштаб только уменьшает. Для увеличения — Увеличение 4×.
💧

Водяной знак пакетно

Идеально для фотографов — наносите водяные знаки до 50 фото за раз.

  1. Нажмите Водяной знак пакетно и Импортируйте до 50 фото.
  2. Тип: Текст или Изображение (логотип PNG).
  3. Позиция в сетке 3×3 с настройкой X/Y.
  4. Живое превью. Начать обработку.
  5. Упаковать и скачать в ZIP.
📐

Изменить размер пакетно

Идеально для уменьшения фото для веба, соцсетей или email.

  1. Нажмите Изменить размер пакетно и Добавить изображения — до 50 фото.
  2. Процент масштаба (10%–200%): 25%, 33%, 50%, 75%.
  3. (Опционально) Формат вывода (PNG, JPEG, WebP, BMP, TIFF).
  4. Живое превью. Обработать всё.
  5. Упаковать и скачать в ZIP.

❓Часто задаваемые вопросы

Нужен ли интернет?

Нет. Всё работает офлайн на вашем устройстве.

Какие форматы поддерживаются?

Импорт: PNG, JPEG, WebP, BMP, TIFF
Экспорт: PNG, JPEG, WebP, BMP, TIFF

Почему обработка ИИ медленнее?

Использует GPU с ONNX Runtime и DirectML. Без совместимого GPU: CPU.

Несколько фото сразу?

Водяной знак пакетно и Изменить размер пакетно (до 50 фото).

Оригинал перезаписывается?

Никогда. Всегда сохраняется как новый файл.

Для чего Подавление шума ИИ?

Уменьшает шум перед основным восстановлением в Восстановлении старых фото.

Как отменить?

Нажмите Отмена на панели инструментов.

Собираются ли мои данные?

Никакого сбора данных.

Какие версии Windows?

Windows 10 (64-бит) и Windows 11 (64-бит).

Почему выбрать PhotoRestore Pro?

Без подписок, без аккаунтов, без загрузок. Полная конфиденциальность.

Разница между Быстрым и ИИ восстановлением?

Быстрое: традиционные алгоритмы, миллисекунды. ИИ: глубокое обучение, 15–60с.

Коммерческое использование?

Да. Без ограничений и водяных знаков.

DirectML?

На современном GPU: в 3–8× быстрее CPU.

Windows on ARM?

Работает через эмуляцию x64.

Возврат средств?

Через Microsoft Store. Сначала попробуйте бесплатную версию.

Приложение вылетает или не запускается

  • Проверьте минимальные требования.
  • Переустановите из Microsoft Store.
