2

インポートして処理

任意の写真を読み込み、「開始」をクリックして、AIエンジンに処理を任せます — すべてデバイス上で実行。

🚀 クイックスタート

  1. Microsoft StoreからPhotoRestore Proをダウンロードします。
  2. アプリを起動 — アカウント、サインアップ、インターネット不要。
  3. ホーム画面から機能を選択します。各カードに機能の説明が表示されます。
  4. ツールバーのインポートボタンをクリックして写真をインポートします。対応形式：PNG、JPEG、WebP、BMP、TIFF。
  5. 画像を処理 — AIツールでは処理開始を、非AIツールではプレビュー生成をクリックします。
  6. 右上隅の保存ボタンをクリックして結果を保存します。
プロのヒント： 任意の機能で画像を処理した後、ホーム画面に戻って別の機能を開くことができます — 元の画像と処理済み画像はそのまま残ります。再インポートせずに複数の強調処理を連鎖させられます。

📷 写真復元

ミリ秒単位の高速補正から完全なAIパイプラインまで、3つの復元アプローチ — 写真の状態に常に最適なツールを選べます。

🗃️

旧写真復元 AI

完全なAI復元が必要な、重度に劣化・退色・変色した家族写真に最適です。

  1. ホーム画面で旧写真復元（AIバッジ付き）をクリックします。
  2. インポートをクリックして写真を選択します。
  3. （オプション） 写真に強いフィルムグレインやデジタルノイズがある場合はAIノイズ除去チェックボックスをオンにします。きれいな写真の場合はオフのままに — 処理時間を節約できます。
  4. 処理開始をクリックします。AIパイプラインは、平滑化、ノイズ除去（有効な場合）、色彩強調、4×アップスケーリング、最終シャープニングの5段階を自動実行します。
  5. 左右比較を確認します。保存をクリックして高品質PNGとしてエクスポートします。
所要時間： 画像サイズとハードウェアにより15〜60秒。DirectMLによるGPUアクセラレーションで処理が大幅に高速化されます。
⚡

高速旧写真復元

軽度に経年劣化したり少し退色した写真で、素早いリフレッシュだけが必要な場合に最適 — AI待ち時間なし、ミリ秒単位で結果表示。

  1. ホーム画面で高速旧写真復元をクリックします。
  2. インポートをクリックして写真を選択します。
  3. 開始をクリック — 結果は即座に表示されます。
  4. ビフォーアフターパネルを比較します。保存をクリックしてエクスポートします。
所要時間： 1秒未満。従来の画像処理アルゴリズムのみを使用 — AIオーバーヘッドなし。
🏛️

クラシック写真復元

美術館、アーカイブ、プロ用スキャナー（600+ DPI）からの高解像度スキャンに最適。アーカイブグレードの真正性のため、元の解像度を保持 — AIアップスケーリングなし。

  1. ホーム画面でクラシック写真復元をクリックします。
  2. インポートをクリックして高解像度スキャンを選択します。
  3. （オプション） スキャンに物理的な傷や折り目がある場合は傷修復をオンにします。
  4. 開始をクリックします。パイプラインは自動的に網点パターンを検出し、画質を分析し、対象を絞った補正を適用 — 手動調整不要。
  5. 保存をクリックして元の解像度でエクスポートします。
所要時間： 2秒未満。完全に決定論的な従来アルゴリズム — 予測可能性が重要なアーカイブワークフローに最適。

🤖 AI画質向上

従来の編集では達成できないレベルまで写真を引き上げる2つの専用AI機能 — 4×超解像アップスケーリングとインテリジェントな白黒カラー化。

🔍

写真アップスケール 4× AI

より詳細が必要な低解像度や圧縮された画像に最適 — 印刷、切り抜き、高品質共有に。

  1. ホーム画面で写真アップスケール 4×（AIバッジ付き）をクリックします。
  2. インポートをクリックして画像を選択します。
  3. 処理開始をクリックします。AIモデルが画像を元の寸法の4倍に拡大し、シャープで自然な細部を復元します。
  4. ビフォーアフターパネルを比較します。保存をクリックしてエクスポートします。
注： 入力バッジに正確な寸法が表示されます — 例：2048 × 1536 → 8192 × 6144。非常に大きな入力（>3メガピクセル）の場合、処理時間の目安がバッジの下に表示されます。
🎨

AIカラー化 AI

白黒やグレースケールの写真に最適 — 手動での塗り作業なしに、歴史が自然で鮮やかな色彩で蘇ります。

  1. ホーム画面でAIカラー化（AIバッジ付き）をクリックします。
  2. インポートをクリックして白黒写真を選択します。
  3. （オプション） AIが最適な色を選択できるように被写体タイプ — ポートレート、風景、建築、一般 — を選択します。
  4. （オプション） 色の強さと暖かさのスライダーを調整して結果を微調整します。
  5. カラー化開始をクリックします。アプリはまずコントラストを強調（約50ms）し、その後AIカラーモデルを実行します。強調された白黒プレビューがすぐに表示されます。
  6. ビフォーアフターパネルを確認します。保存をクリックしてエクスポートします。
所要時間： AIカラー化に4〜8秒。即時のコントラストプレビューで、モデル動作中も待たされません。

🛠️ スマートツール

日常的な写真作業のための6つの軽量で超高速なユーティリティ — AI不要、待ち時間ゼロ、すぐに結果が出ます。

✨

色彩強調

くすんだり平坦に見えるカラー写真に最適 — 8つのビジュアルプリセットを並べてプレビューし、お気に入りを選択。

  1. ホーム画面で色彩強調をクリックし、写真をインポートします。
  2. プレビュー生成をクリック — 8つのプリセットがすべて同時にレンダリングされます。
  3. サムネイルストリップを閲覧します。任意のサムネイルをクリックするか← / →矢印キーで切り替え：ナチュラル＆クリスプ、ブライト＆ライブリー、ウォームグロー、リッチ＆ビビッド、クール＆クリスプ、ソフト＆ドリーミー、ビンテージフィルム、ウルトラサチュレート。
  4. 選択をエクスポートをクリックしてお気に入りをフル解像度で保存します。
🔧

傷・折れ修復

物理的な損傷による目に見える傷、破れ、折り目があるスキャン写真に最適。

  1. ホーム画面で傷・折れ修復をクリックし、スキャンした写真をインポートします。
  2. 修復開始をクリックします。アプリは形態学的分析で傷を検出し、インテリジェントなインペインティングで損傷領域を埋め、修復領域全体のコントラストを復元します。
  3. 確認して保存をクリック。所要時間：1〜3秒。
重要： このツールは物理的損傷を対象とします。全体的な経年劣化（退色、変色）には、代わりに旧写真復元またはクラシック写真復元を使用してください。
🎞️

9スタイルフィルターグリッド

芸術的なスタイルを素早くブラウズするのに最適 — 9つのフィルターすべてが並列レンダリングされ、即座に比較できます。

  1. 9スタイルフィルターグリッドをクリックし、写真をインポートします。
  2. プレビュー生成をクリック — 9つのフィルターすべてが同時にレンダリングされます。
  3. サムネイルを閲覧するか矢印キーで切り替え：白黒、ビンテージウォーム、クールティール、フィルムグレイン、ハイコントラスト、ソフトグロー、ジャパンフレッシュ、マットフェード、サイバーパンク。
  4. 選択をエクスポートをクリックしてフル解像度で保存します。
✂️

切り抜き＆変換

写真のトリミング、リサイズ、画像形式間の変換に最適 — 日常的な準備作業を処理する軽量ユーティリティ。

  1. 切り抜き＆変換をクリックし、写真をインポートします。
  2. モードを選択：ドラッグ選択（自由選択）、指定サイズ（ピクセル単位）、拡大縮小（パーセント縮小）。
  3. 出力形式を選択：PNG、JPEG、WebP、BMP、TIFF。JPEG/WebPの品質を調整します。
  4. プレビュー適用をクリックし、エクスポートします。
注： 拡大縮小モードはサイズ縮小のみです。画像を拡大するには写真アップスケール 4×を使用してください。
💧

バッチ透かし

写真家やコンテンツクリエイターに最適 — 最大50枚の写真に一度にテキストまたはロゴの透かしを追加。

  1. バッチ透かしをクリックし、最大50枚の写真をインポートします。
  2. 透かしタイプを選択：テキスト（テキスト入力、フォント/サイズ/色/不透明度を選択）または画像（PNGロゴを選択）。
  3. 位置を設定 — 9グリッド位置（左上、中央、右下など）を選び、X/Yオフセットで微調整。
  4. ライブプレビューを確認。パラメータを調整 — プレビューは自動更新。
  5. 処理開始をクリック。すべての写真が同時に透かし処理されます。
  6. パッケージ化＆ダウンロードをクリックしてZIPファイルを取得。
📐

バッチ画像リサイズ

Webアップロード、SNS、メール用に写真を一括縮小するのに最適 — フォーマット変換も一度に。

  1. バッチ画像リサイズをクリックし、画像を追加 — 最大50枚。
  2. 拡大縮小率（10%–200%）を設定するか、プリセット（25%、33%、50%、75%）を選択。
  3. （オプション） 出力形式（PNG、JPEG、WebP、BMP、TIFF）を選択し、JPEG/WebPの品質を調整。
  4. ライブプレビューを確認 — 設定変更に応じて寸法が更新されます。
  5. すべて処理をクリック。画像は同時にリサイズされます。
  6. パッケージ化＆ダウンロードをクリックしてZIPファイルを取得。

❓ よくある質問

PhotoRestore Proを使うのにインターネット接続は必要ですか？

いいえ。すべてのAIモデルと処理は完全にオフラインでお使いのデバイス上で実行されます。インストール後はインターネット接続は一切不要です。つまり、写真がコンピューターから出ることはありません — 完全なプライバシー、クラウド依存ゼロ。

対応している画像形式は何ですか？

インポート： PNG、JPEG、WebP、BMP、TIFF
エクスポート： PNG（デフォルト、ロスレス）、JPEG（品質調整可）、WebP（品質調整可）、BMP、TIFF

自分のコンピューターでAI処理が遅いのはなぜですか？

AIモデルはONNX Runtime with DirectMLを介してGPUをアクセラレーションに使用します。お使いのGPUがDirectMLをサポートしていないかVRAMが限られている場合、アプリは自動的にCPU処理に切り替わります — 遅くなりますが、どのWindows PCでも動作します。最高の体験にはDirectML対応GPUが推奨されます。

複数の写真を一度に処理できますか？

バッチ処理は2つのツールで利用可能：バッチ透かし（最大50枚）とバッチ画像リサイズ（最大50枚）。その他の機能は最高品質のため1枚ずつ処理します。機能を連鎖できます — 1つのツールで処理し、ホームに戻り、別のツールを開く — 進行状況は保持されます。

元の写真は上書きされますか？

決して上書きされません。PhotoRestore Proは常に結果を新しいファイルとして保存します。元の画像が変更されることはありません。

AIノイズ除去チェックボックスは何をするのですか？

旧写真復元では、AIノイズ除去はメインの復元パイプラインの前にディープラーニングのノイズ除去モデルを実行します。強いグレインやデジタルノイズのある写真で有効にしてください。きれいな写真ではオフのままに — 処理時間を大幅に節約できます。

処理操作をキャンセルするには？

ツールバーのキャンセルボタンをクリックします。現在の操作が停止し、アプリは準備完了状態に戻ります。すぐに再開できます。

データは収集・共有されますか？

いかなるデータ収集もありません。PhotoRestore Proには、分析、テレメトリ、クラッシュレポート、ネットワーク通信は一切含まれていません。すべての画像の全ピクセルは、お使いのコンピューターのメモリ内でのみ処理されます。

どのWindowsバージョンがサポートされていますか？

Windows 10（64ビット）およびWindows 11（64ビット）。両方とも完全にサポートされています。

なぜユーザーはクラウドベースの代替品よりもPhotoRestore Proを選ぶのですか？

PhotoRestore Proは、サブスクリプション、アカウント、クラウドアップロードの煩わしさなしに、大切な思い出の復元という普遍的で現実的な問題を解決するからです。写真は完全にデバイス上で処理されます：アップロードによる遅延ゼロ、完全なプライバシー、そしてクラウドサービスに匹敵または凌駕する結果。箱から出してすぐに動作します。

高速復元とAI旧写真復元の違いは何ですか？

高速復元は従来の画像処理アルゴリズムを使用 — ミリ秒単位で結果が表示され、軽度の退色写真に最適です。AI復元は完全なディープラーニングパイプライン（平滑化、ノイズ除去、色彩強調、4×アップスケーリング、シャープニング）を15〜60秒実行し、重度に劣化・損傷した写真向けに設計されています。忍耐力ではなく、写真の状態に基づいて選択してください。

PhotoRestore Proを商用目的で使用できますか？

はい。PhotoRestore Proで処理した写真は商用目的 — クライアントワーク、印刷、出版、SNS — に使用できます。書き出した画像に使用制限や透かしはありません。ツールはあなたのもの、結果もあなたのものです。

DirectMLアクセラレーションは処理速度にどのように影響しますか？

DirectMLは、GPUの専用AIコア（利用可能な場合）を使用してONNX Runtime推論を高速化します。最新のGPUでは、AIツールはCPUのみのモードより3〜8倍高速に動作します。アプリはハードウェアを自動検出し、最速のバックエンドを選択します — 手動設定不要。

アプリはWindows on ARM（Snapdragon）で動作しますか？

PhotoRestore Proはx64アーキテクチャ向けにコンパイルされており、Windows 10/11 x64エディションで動作します。ARMベースのWindowsデバイス（例：Snapdragon X Elite）ではx64エミュレーションを介して実行可能ですが、AI処理速度は変動する可能性があります。ネイティブARM64サポートは将来のリリースで検討中です。

満足できない場合の返金方法は？

すべての購入はMicrosoft Storeを通じて処理され、標準の返金ポリシーが提供されます。Microsoftアカウントの注文履歴から直接返金をリクエストできます。購入前にアプリがニーズを満たすことを確認するために無料トライアルをお試しいただくことをおすすめします。

💡 最良の結果を得るためのヒント

一般的なヒント

  • 可能な限り高品質のソースから始めてください。AI復元でも良いデータからが最良の結果です。
  • 複雑な復元には機能を連鎖させてください。例：傷・折れ修復 → 旧写真復元 → 色彩強調。
  • 中間結果を保存してください。必要に応じて戻れるよう、各機能の後に保存しましょう。
  • 軽度の退色写真は高速旧写真復元で1秒未満で見違えるほど良くなることが多いです。

古い家族写真の場合

  • 物理的なプリントからの最良の結果を得るには300〜600 DPIでスキャンしてください。
  • 傷と経年劣化の両方がある写真の場合：最初に傷修復、次に旧写真復元。
  • きれいなスキャンではAIノイズ除去を避けてください — ノイズのない写真では時間がかかるだけでメリットは最小限です。

白黒のカラー化の場合

  • 適切な被写体タイプを選択 — 人物にはポートレート、自然には風景、建物には建築。
  • デフォルト設定から始め、必要に応じて微調整してください。
  • コントラストの良いグレースケール写真の方がカラー化の結果が良いです — 画像が平坦な場合は最初に高速旧写真復元を使用してください。

バッチ操作の場合

  • 50枚すべてを処理する前にまず2〜3枚でテストしてください。
  • 安全策としてオリジナルのバックアップを別フォルダに保管してください。

🔧 トラブルシューティング

一般的な問題のクイックフィックス — ほとんどの問題は1分以内に解決できます。

AI処理が非常に遅い

  • GPUドライバが最新であることを確認してください（NVIDIA Game Ready / AMD Adrenalin / Intel Arc）。
  • DirectMLが利用可能か確認 — アプリは起動時に推論バックエンドをログに記録します。
  • 他のGPU負荷の高いアプリケーション（ビデオエディタ、ゲーム、WebGLブラウザ）を閉じてください。
  • 入力画像サイズを縮小 — 12MPの写真をCPUで処理すると3MPのものより時間がかかります。

アプリがクラッシュする、または起動しない

  • システムが最小要件を満たしていることを確認してください（Windows 10 64ビット、4 GB RAM）。
  • Microsoft Storeから再インストール — すべての依存関係が正しくパッケージ化されます。
  • アンチウイルスを使用している場合は、一時的にPhotoRestore Proを除外リストに追加してください。

カラー化の結果が不自然に見える

  • 別の被写体タイプを試してください — ポートレートモードは風景より肌色の処理が優れています。
  • 色の強さを下げてより控えめな効果にし、徐々に上げてください。
  • 入力写真のコントラストが良好であることを確認 — 画像が平坦または色あせている場合は、最初に高速旧写真復元を実行してください。

傷修復で一部の傷が残った

  • 深いまたは広い傷の場合は傷修復を2回実行してください — 各パスで残りの隙間が埋まります。
  • 300+ DPIでスキャンしてください — 低解像度スキャンでは傷の検出が難しくなります。
  • 最良の最終結果を得るには、傷修復後に旧写真復元（AI）と組み合わせてください。
