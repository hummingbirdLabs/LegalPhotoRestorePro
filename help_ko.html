🗃️

오래된 사진 복원 AI

완전한 AI 기반 복원이 필요한 심하게 노화, 퇴색 또는 변색된 가족 사진에 가장 적합합니다.

  1. 홈 화면에서 AI 배지가 표시된 오래된 사진 복원을 클릭하세요.
  2. 가져오기를 클릭하고 사진을 선택하세요.
  3. (선택 사항) 사진에 심한 필름 그레인이나 디지털 노이즈가 있는 경우 AI 노이즈 제거 확인란을 선택하세요. 깨끗한 사진은 꺼두세요 — 처리 시간이 절약됩니다.
  4. 처리 시작을 클릭하세요. AI 파이프라인이 자동으로 5단계 실행: 평활화, 노이즈 제거(활성화된 경우), 색상 향상, 4배 업스케일 및 최종 선명화.
  5. 병렬 비교를 검토하세요. 저장을 클릭하여 고품질 PNG로 내보내세요.
시간: 이미지 크기와 하드웨어에 따라 15~60초. DirectML을 통한 GPU 가속이 처리 속도를 크게 향상시킵니다.
⚡

빠른 오래된 사진 복원

약간 노화되었거나 살짝 퇴색된 사진에 가장 적합 — AI 대기 시간 없음, 결과가 밀리초 내에 표시됩니다.

  1. 홈 화면에서 빠른 오래된 사진 복원을 클릭하세요.
  2. 가져오기를 클릭하고 사진을 선택하세요.
  3. 시작을 클릭하세요 — 결과가 즉시 표시됩니다.
  4. 전후 패널을 비교하세요. 저장을 클릭하여 내보내세요.
시간: 1초 미만. 전통적인 이미지 처리 알고리즘만 사용 — AI 오버헤드 없음.
🏛️

클래식 사진 복원

박물관, 아카이브 또는 전문 스캐너(600+ DPI)의 고해상도 스캔에 가장 적합합니다. 원본 해상도를 보존 — AI 업스케일 없음 — 아카이브급 진정성을 위해.

  1. 홈 화면에서 클래식 사진 복원을 클릭하세요.
  2. 가져오기를 클릭하고 고해상도 스캔을 선택하세요.
  3. (선택 사항) 스캔에 물리적 스크래치나 접힌 선이 있는 경우 스크래치 복구를 켜세요.
  4. 시작을 클릭하세요. 파이프라인이 자동으로 하프톤 패턴 감지, 이미지 품질 분석 및 대상 보정 적용 — 수동 조정 불필요.
  5. 저장을 클릭하여 원본 해상도로 내보내세요.
시간: 2초 미만. 완전히 결정론적인 전통적 알고리즘 — 예측 가능성이 중요한 아카이브 워크플로에 이상적.

🤖AI 향상

전통적인 편집이 달성할 수 없는 수준으로 사진을 끌어올리는 두 가지 전용 AI 기능 — 4배 초해상도 업스케일링과 지능형 흑백 컬러화.

🔍

사진 4배 업스케일 AI

더 많은 디테일이 필요한 저해상도 또는 압축된 이미지에 가장 적합 — 인쇄, 자르기 또는 더 높은 품질로 공유하는 데 이상적.

  1. 홈 화면에서 AI 배지가 표시된 사진 4배 업스케일을 클릭하세요.
  2. 가져오기를 클릭하고 이미지를 선택하세요.
  3. 처리 시작을 클릭하세요. AI 모델이 이미지를 원본 크기의 4배로 확대하면서 선명하고 자연스러운 디테일을 복구합니다.
  4. 전후 패널을 비교하세요. 저장을 클릭하여 내보내세요.
참고: 입력 배지에 정확한 크기가 표시됩니다 — 예: 2048 × 1536 → 8192 × 6144. 매우 큰 입력(>3메가픽셀)의 경우 배지 아래에 처리 시간 추정치가 표시됩니다.
🎨

AI 컬러화 AI

흑백 또는 그레이스케일 사진에 가장 적합 — 수동 페인팅 없이 역사가 자연스럽고 생생한 색상으로 살아납니다.

  1. 홈 화면에서 AI 배지가 표시된 AI 컬러화를 클릭하세요.
  2. 가져오기를 클릭하고 흑백 사진을 선택하세요.
  3. (선택 사항) AI가 최상의 색상을 선택하도록 주제 유형 선택 — 인물, 풍경, 건축 또는 일반.
  4. (선택 사항) 색상 강도 및 따뜻함 슬라이더를 조정하여 결과를 미세 조정하세요.
  5. 처리 시작을 클릭하세요. AI가 객체, 질감 및 그림자를 분석하여 사실적인 색상을 적용합니다.
  6. 검토하고 저장을 클릭하세요.
시간: 이미지 크기에 따라 10~40초. 주제 유형을 선택하면 색상 정확도가 향상됩니다.

🧰스마트 도구

색상 조정, 물리적 손상 복구, 창의적 필터, 형식 변환 및 일괄 작업을 위한 6가지 실용적 도구.

🌈

색상 향상

색상 균형, 채도 및 대비를 미세 조정하는 데 가장 적합 — 정밀한 제어를 위한 조정 가능한 슬라이더가 있는 9가지 프리셋.

  1. 색상 향상을 클릭한 후 가져오기로 사진을 불러오세요.
  2. 화살표 키로 프리셋 순환: 선명, 따뜻, 차가움, 드라마, 부드러움, 시네마, 빈티지, 숲, 바다.
  3. (선택 사항) 슬라이더로 밝기, 대비, 채도, 색온도 및 선명도를 수동 조정.
  4. 실시간 미리보기를 검토하고 저장을 클릭.
🩹

스크래치 및 주름 복구

스캔한 사진에서 보이는 물리적 손상에 가장 적합 — 스크래치, 주름 및 찢김을 자동 감지하고 복구합니다.

  1. 스크래치 및 주름 복구를 클릭한 후 스캔한 사진을 가져오기.
  2. 복구 시작을 클릭. 앱이 형태학적 분석을 통해 스크래치 감지, 지능적 인페인팅으로 손상 영역 채우기 및 복구 영역의 대비 복원.
  3. 검토하고 저장 클릭. 시간: 1~3초.
중요: 이 도구는 물리적 손상을 대상으로 합니다. 일반 노화(퇴색, 변색)는 오래된 사진 복원 또는 클래식 사진 복원을 사용하세요.
🎞️

9스타일 필터 그리드

예술적 스타일을 빠르게 탐색하는 데 가장 적합 — 9가지 필터가 모두 병렬로 렌더링되어 즉시 비교 가능.

  1. 9스타일 필터 그리드를 클릭한 후 사진 가져오기.
  2. 미리보기 생성 클릭 — 9가지 필터 동시 렌더링.
  3. 썸네일 탐색 또는 화살표 키로 전환: 흑백, 빈티지 웜, 쿨 틸, 필름 그레인, 하이 콘트라스트, 소프트 글로우, 재팬 프레시, 매트 페이드, 사이버펑크.
  4. 선택 내보내기를 클릭하여 전체 해상도로 저장.
✂️

자르기 및 변환

이미지 형식 간 트리밍, 크기 조정 또는 변환에 가장 적합 — 일상적인 준비 작업을 처리하는 경량 유틸리티.

  1. 자르기 및 변환을 클릭한 후 사진 가져오기.
  2. 모드 선택: 드래그 선택(자유형), 지정 크기(정확한 픽셀) 또는 비율(백분율 축소).
  3. 출력 형식 선택: PNG, JPEG, WebP, BMP 또는 TIFF. JPEG/WebP 품질 조정.
  4. 미리보기 적용 후 내보내기.
참고: 비율 모드는 크기만 축소합니다. 이미지 확대는 사진 4배 업스케일을 사용하세요.
💧

배치 워터마크

사진작가 및 콘텐츠 제작자에게 가장 적합 — 최대 50장의 사진에 텍스트 또는 로고 워터마크를 한 번에 추가.

  1. 배치 워터마크 클릭 후 최대 50장 사진 가져오기.
  2. 워터마크 유형 선택: 텍스트(텍스트 입력, 글꼴/크기/색상/투명도 선택) 또는 이미지(PNG 로고 선택).
  3. 위치 설정 — 9그리드 위치 선택(좌측상단, 중앙, 우측하단 등) 및 X/Y 오프셋 미세 조정.
  4. 실시간 미리보기 검토. 매개변수 조정 — 미리보기 자동 업데이트.
  5. 처리 시작 클릭. 모든 사진 동시 워터마크.
  6. 패키지 및 다운로드를 클릭하여 ZIP 파일 받기.
📐

배치 이미지 크기 조정

웹 업로드, 소셜 미디어 또는 이메일용 사진 일괄 축소에 가장 적합 — 한 번에 형식 변환 포함.

  1. 배치 이미지 크기 조정 클릭 후 이미지 추가 — 최대 50장.
  2. 비율 백분율(10%~200%) 설정 또는 프리셋 선택: 25%, 33%, 50% 또는 75%.
  3. (선택 사항) 출력 형식 선택(PNG, JPEG, WebP, BMP, TIFF) 및 JPEG/WebP 품질 조정.
  4. 실시간 미리보기 검토 — 설정 변경 시 크기 업데이트.
  5. 모두 처리 클릭. 이미지 동시 크기 조정.
  6. 패키지 및 다운로드로 ZIP 파일 받기.

❓자주 묻는 질문

PhotoRestore Pro를 사용하려면 인터넷 연결이 필요한가요?

아니요. 모든 AI 모델과 처리는 기기에서 완전히 오프라인으로 실행됩니다. 설치 후에는 인터넷 연결이 전혀 필요하지 않습니다. 사진이 컴퓨터를 떠나지 않습니다 — 완전한 개인정보 보호, 클라우드 의존성 제로.

어떤 이미지 형식을 지원하나요?

가져오기: PNG, JPEG, WebP, BMP, TIFF
내보내기: PNG(기본값, 무손실), JPEG(품질 조정 가능), WebP(품질 조정 가능), BMP, TIFF

내 컴퓨터에서 AI 처리가 느린 이유는 무엇인가요?

AI 모델은 ONNX Runtime with DirectML을 통해 GPU를 가속에 사용합니다. GPU가 DirectML을 지원하지 않거나 VRAM이 제한된 경우 앱이 자동으로 CPU 처리로 전환됩니다 — 느리지만 모든 Windows PC에서 작동합니다. 최상의 경험을 위해 DirectML 호환 GPU 권장.

한 번에 여러 장의 사진을 처리할 수 있나요?

두 가지 도구에서 일괄 처리 가능: 배치 워터마크(최대 50장) 및 배치 이미지 크기 조정(최대 50장). 다른 모든 기능은 최고 품질을 위해 한 번에 한 장씩 처리합니다. 기능 연결 가능 — 한 도구에서 처리 후 홈으로 돌아가 다른 도구 열기 — 진행 상황 유지.

원본 사진이 덮어쓰기되나요?

절대 아닙니다. PhotoRestore Pro는 항상 결과를 새 파일로 저장합니다. 원본 이미지는 절대 수정되지 않습니다.

AI 노이즈 제거 체크박스는 무엇을 하나요?

오래된 사진 복원에서 AI 노이즈 제거는 주요 복원 파이프라인 전에 딥러닝 노이즈 감소 모델을 실행합니다. 심한 그레인이나 디지털 노이즈가 있는 사진에 활성화하세요. 깨끗한 사진은 꺼두세요 — 처리 시간 크게 절약.

처리 작업을 어떻게 취소하나요?

도구 모음에서 취소 버튼 클릭. 현재 작업 중지 후 앱이 준비 상태로 돌아갑니다. 즉시 다시 시작 가능.

데이터가 수집되거나 공유되나요?

어떠한 데이터 수집도 없습니다. PhotoRestore Pro에는 분석, 원격 측정, 충돌 보고 또는 네트워크 통신이 포함되지 않습니다. 모든 픽셀은 컴퓨터 메모리 내에서만 처리됩니다.

어떤 Windows 버전이 지원되나요?

Windows 10(64비트) 및 Windows 11(64비트). 둘 다 완전히 지원됩니다.

사용자들이 클라우드 기반 대안 대신 PhotoRestore Pro를 선택하는 이유는?

PhotoRestore Pro가 실제 보편적 문제 — 소중한 추억 복원 — 를 구독, 계정 또는 클라우드 업로드의 마찰 없이 해결하기 때문입니다. 사진이 완전히 기기에서 처리됩니다: 업로드 지연 제로, 완전한 개인정보 보호, 클라우드 서비스에 필적하거나 능가하는 결과. 바로 사용 가능합니다.

빠른 복원과 AI 오래된 사진 복원의 차이점은?

빠른 복원은 전통적인 이미지 처리 알고리즘 사용 — 결과가 밀리초 내 표시, 빠른 새로고침만 필요한 약간 바랜 사진에 이상적. AI 복원은 전체 딥러닝 파이프라인(평활화, 노이즈 제거, 색상 향상, 4배 업스케일, 선명화)을 15~60초 동안 실행, 심하게 노화되거나 손상된 사진용. 인내심이 아닌 사진 상태에 따라 선택하세요.

PhotoRestore Pro를 상업적 작업에 사용할 수 있나요?

네. PhotoRestore Pro로 처리한 사진은 상업적 목적 — 클라이언트 작업, 인쇄, 출판, 소셜 미디어에 사용 가능. 내보낸 이미지에 사용 제한이나 워터마크 없음. 도구는 당신의 것, 결과도 당신의 것.

DirectML 가속이 처리 속도에 어떤 영향을 미치나요?

DirectML은 GPU의 전용 AI 코어(사용 가능한 경우)를 사용하여 ONNX Runtime 추론 가속. 최신 GPU에서 AI 도구는 CPU 전용 모드보다 3~8배 빠르게 실행. 앱이 자동으로 하드웨어 감지 후 최적 백엔드 선택 — 수동 구성 불필요.

Windows on ARM(Snapdragon)에서 작동하나요?

PhotoRestore Pro는 x64 아키텍처용으로 컴파일되었으며 Windows 10/11 x64 에디션에서 실행. ARM 기반 Windows 기기(예: Snapdragon X Elite)는 x64 에뮬레이션을 통해 앱 실행 가능하나 AI 처리 속도는 다를 수 있음. 네이티브 ARM64 지원은 향후 릴리스에서 평가 중.

만족스럽지 않으면 환불은 어떻게 받나요?

모든 구매는 Microsoft Store를 통해 처리되며 표준 환불 정책 제공. Microsoft 계정의 주문 내역에서 직접 환불 요청 가능. 구매 전 무료 체험판을 먼저 사용해 보시는 것을 권장합니다.

일반 팁

  • 복잡한 복원을 위해 기능 연결. 예: 스크래치 복구 → 오래된 사진 복원 → 색상 향상.
  • 중간 결과 저장. 필요 시 되돌릴 수 있도록 각 기능 후 저장.

오래된 가족 사진용

  • 실물 인화에서 최상 결과를 위해 300~600 DPI로 스캔.
  • 스크래치와 노화가 모두 있는 사진: 스크래치 복구 먼저, 그 다음 오래된 사진 복원.
  • 깨끗한 스캔에는 AI 노이즈 제거 피하기 — 노이즈 없는 사진에 최소한의 이점으로 시간 추가.

흑백 컬러화용

  • 올바른 주제 유형 선택 — 인물은 인물, 자연은 풍경, 건물은 건축.
  • 먼저 기본 설정으로 시작 후 필요 시 미세 조정.
  • 대비가 좋은 그레이스케일 사진이 컬러화 더 잘 됨 — 이미지가 평탄하면 먼저 빠른 오래된 사진 복원 사용.

일괄 작업용

  • 전체 50장 처리 전 먼저 2~3장으로 테스트.
  • 안전망으로 원본 백업을 별도 폴더에 보관.

🔧문제 해결

일반적인 문제에 대한 빠른 해결책 — 대부분 1분 이내 해결 가능.

AI 처리 속도가 매우 느림

  • GPU 드라이버가 최신인지 확인 (NVIDIA Game Ready / AMD Adrenalin / Intel Arc).
  • DirectML 사용 가능 확인 — 앱 시작 시 추론 백엔드 기록.
  • 다른 GPU 집중 앱(비디오 편집기, 게임, WebGL 브라우저) 닫기.
  • 입력 이미지 크기 줄이기 — CPU에서 12MP 사진 처리 시 3MP보다 훨씬 오래 걸림.

앱 충돌 또는 시작 불가

  • 시스템이 최소 요구 사항 충족 확인 (Windows 10 64비트, 4GB RAM).
  • Microsoft Store에서 재설치 — 모든 종속성 올바르게 패키징 보장.
  • 바이러스 백신 사용 시 PhotoRestore Pro를 제외 목록에 임시 추가.

컬러화 결과가 부자연스러움

  • 다른 주제 유형 시도 — 인물 모드가 풍경보다 피부톤 처리 우수.
  • 더 미묘한 효과를 위해 색상 강도 줄인 후 점진적 증가.
  • 입력 사진 대비 양호 확인 — 이미지가 평탄하거나 바랜 경우 먼저 빠른 오래된 사진 복원 실행.

스크래치 복구가 일부 스크래치 놓침

  • 깊거나 넓은 스크래치의 경우 스크래치 복구 두 번 실행 — 각 패스가 남은 간격 채움.
  • 300+ DPI로 스캔 — 저해상도 스캔은 스크래치 감지 어렵게 함.
  • 스크래치 복구 후 오래된 사진 복원(AI)과 결합하여 최상의 최종 결과.
